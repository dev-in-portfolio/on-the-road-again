# On The Road Again 🚗💨

> Temporary developer staging pad & road trip command center.

## Features

- **Interactive Scratchpad**: Auto-saves text locally with instant copy and stats.
- **Route Checkpoints**: Manage and check off road trip stops & milestones.
- **Ambient Sound Synthesizer**: Procedural Web Audio background soundscapes (highway rain, synth sunset).
- **Dynamic Gradient Theme Shifter**: Customize accent colors on the fly.
- **Modern UI**: Dark glassmorphism styling, responsive layout, fluid animations.

## Getting Started

Open `index.html` in your browser, or launch a quick dev server:

```bash
npx serve .
```
